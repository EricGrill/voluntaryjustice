# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x (mainnet) | ✅ Security patches |
| < 1.0 (testnet) | ⚠️ Best effort |

## Reporting a Vulnerability

VoluntaryJustice handles real economic value. If you discover a security vulnerability, please report it responsibly.

**Please DO NOT:**
- Open a public issue for security vulnerabilities
- Discuss vulnerabilities in public channels before a fix is deployed

**Please DO:**
- Email security concerns to: **security@ericgrill.com**
- Include detailed steps to reproduce
- Allow up to 72 hours for initial response
- Provide a reasonable timeframe for remediation before public disclosure

## Scope

The following are in scope for vulnerability reports:

- Smart contracts in the `contracts/` directory
- Deployment and upgrade scripts in `scripts/`
- Frontend wallet connection and transaction signing logic
- Governance and privileged access controls

Out of scope:
- Third-party dependencies (report to respective projects)
- Frontend UI/UX issues without security impact
- Previously disclosed vulnerabilities

## Recognition

We will publicly acknowledge responsible disclosures (with your permission) in our release notes and SECURITY.md.
